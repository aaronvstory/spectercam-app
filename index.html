Inside the download

Desktop app

SpecterCam.exe — a portable Windows app. No install. It picks the video and drives the phone.

Phone app

SpecterCam-1.5.108.apk — install it on the Android phone. It feeds the video into the camera.

OBS & RTMP

The RTMP server is bundled. Point OBS at it and stream a live scene through to the phone.

Set it up

On the PC Windows x64

  1. Unzip the download.
  2. Run SpecterCam.exe. Windows may warn about a new app — allow it.
  3. Connect the phone by USB or Wi-Fi. The app finds it and shows a live preview.
  4. Pick a video. The preview shows exactly what the phone captures.

On the phone Android

  1. Copy SpecterCam-1.5.108.apk to the phone.
  2. Open it and install. Allow install from this source if asked.
  3. Open SpecterCam and turn the virtual camera on.
  4. Open any camera app. It shows the video from the PC.

This is the licensed build

The first run starts a free trial. To keep using it, activate with a code.

The phone app shows its device ID on the Activation screen. Send that ID and you get a code back.

New in v1.5.108

  • Auto fps, width and aspect. The output follows the clip. A 24fps video streams at 24, with no judder.
  • The preview matches the phone. Drag the frame and it lands where you put it, on both cameras.
  • Live clip facts. The preview shows the current video resolution, fps, size and length.
  • Reset recovers a stalled phone. A locked or backgrounded phone no longer leaves the stream dead.
  • Steadier feed. The preview holds its last frame through a restart instead of cutting out.
